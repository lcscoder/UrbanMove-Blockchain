
# UrbanMove Blockchain

## Blockchain-based Taxi Booking and Journey Management System

### Project Overview

UrbanMove is a blockchain-based taxi booking and journey management prototype developed for UrbanMove Taxi Services, an Irish taxi company.

The project explores how blockchain technology and smart contracts can improve transparency, security, trust and efficiency in taxi booking and payment processes.

### Project Objectives

- Develop a smart contract for taxi bookings.
- Automate passenger and driver interactions.
- Manage taxi fare payments using Solidity.
- Improve transparency in journey records.
- Demonstrate the benefits and limitations of blockchain technology.

### Technologies

- Solidity
- Remix IDE
- MetaMask
- Ganache
- Python
- Shell Script
- Git and GitHub
